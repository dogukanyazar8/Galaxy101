- MP3 SHA256: `21547F79EAE38AE1AE7F494E0AC4FFFADDF61258BACA5EA9888040611197AFE0`.
- This is the freely accessible preview, not the original login-only download. No account or authentication was used.
- `macif-329100-preview-decoded.wav` is that preview decoded to44.1kHz/stereo/16bitPCM with Blender5.2.2 aud.Sound.write. It is not the author's original32bitWAV.
- Derived clips: individual physical contacts at1.50/2.69/3.40seconds, mono downmix, rumble reduction, softened high frequencies, short boundary fades and quiet gain. No synthesized tone or pitch shift added.
- Reproduce with `python scripts/prepare-table-audio.py --output <directory>`. Only draw/place/discard WAV files are game assets. Listening preview/evidence stay outside Unity Assets.
- T11's synthetic sounds were rejected by the user as unpleasant and lacking real game feel. This first physical-recording candidate was also rejected as harsh/artificial. It has not been applied to Unity assets. A reference application/video was requested; sound acceptance remains open.
